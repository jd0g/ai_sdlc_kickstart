# Build and Packaging Layer

Generated client deployment artifacts and packaging automation belong here.

Canonical source lives only in `standards/`, `skills/`, `schemas/`, and `evaluations/`. Generated artifacts must be reproducible and must not become editable source-of-truth copies.

Planned outputs can include:
- Cursor client artifacts
- GitHub Copilot instruction artifacts
- Copilot Studio consolidated instruction/knowledge artifacts
- Validation reports
