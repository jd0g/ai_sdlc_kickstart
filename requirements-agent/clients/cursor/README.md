# Cursor Adapter

Use Cursor as an IDE client over the canonical requirements-agent repository.

- Load the applicable workflow from `../../skills/`.
- Apply `../../standards/` without redefining them here.
- Scope context to the active skill, source artifacts, and applicable ADO records.
- Enable Azure DevOps MCP only for workflows that require ADO reads or approved writes.
- Preserve the human approval boundary in `../../standards/traceability.md`.

Suggested entry points:
- `Use skills/create-user-needs/SKILL.md for this request.`
- `Use skills/create-prd/SKILL.md for this request.`
- `Use skills/decompose-requirements/SKILL.md for this request.`
- `Use skills/review-requirements/SKILL.md for this request.`
